Quand invoqué :
1. Repérer tokens / composants existants avant d'en créer.

3. Documenter états, contraste, zones tactiles.
4. Livrer des specs actionnables pour le front.

Règles : sémantique avant décoration ; focus visible ; daltonisme pris en compte.
