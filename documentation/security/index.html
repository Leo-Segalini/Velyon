Sécurité de cette livraison

  • Aucun secret dans le code. .env est ignoré, .env.example ne contient que des emplacements.
  • En-têtes HTTP (nosniff, frame, referrer, permissions). La CSP est active en production.
  • La route PDF ne navigue pas vers une adresse fournie par le client. Seuls le modèle et le format, bornés par une liste, sont acceptés.
  • Cinq exports PDF par minute et par adresse. Réponse 429 avec Retry-After.
  • Les noms de police injectés dans le CSS perdent tout caractère hors lettres, chiffres, espace et tiret.
  • Le filigrane est décidé dans les données serveur, pas par un paramètre d’URL.

Pas encore en place

  • Authentification, isolation des fichiers par utilisateur, assainissement SVG : ils arrivent avec l’import.
  • Stripe et le filigrane lié à l’offre réelle.
  • File d’attente pour les rendus. Aujourd’hui un Chromium est lancé par requête, ce qui est acceptable pour la démo et trop lourd pour la charge.
