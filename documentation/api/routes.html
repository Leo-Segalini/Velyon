Routes

MéthodeCheminAuthDétail
POST /api/chat Publique JSON : messages (1 à 30 messages, rôle user ou assistant, 4 000 caractères). Le dernier message vient de l’utilisateur. Réponse : message, et documents seulement si la rédaction des trois pièces est demandée. 422 si le corps est invalide. 429 au-delà de 20 messages par minute.
GET /api/charte/pdf Publique (démo) Ancien export de charte, conservé dans le dépôt, hors parcours produit. Query template et format. 429 au-delà de 5 appels par minute.
