Pipeline PDF

L’aperçu /charte/apercu et l’export GET /api/charte/pdf affichent le même composant BrandBook. La route lance Chromium, ouvre cette page en média print et laisse la règle @page fixer le format.

  1. La marque est résolue : HEX valides, rôles manquants remplacés, avertissements listés.
  2. Les variables CSS sont posées sur la racine du document.
  3. Les sections actives deviennent des planches de format fixe.
  4. Playwright attend les polices et les images, puis imprime.

Le filigrane n’est pas un paramètre d’URL. Il est une donnée serveur (watermark). La démo le laisse désactivé. L’offre gratuite l’activera avec l’abonnement, pas depuis le navigateur.

La route est limitée à 5 générations par minute et par adresse. Chromium doit être installé (npx playwright install chromium).
