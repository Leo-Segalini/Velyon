Dossier d’avant-vente

18 novembre 2026 · v0.2.0 · Stable

Description

L’accueil est une discussion. On décrit le projet, Velyon répond dans le fil, puis rédige le cahier des charges, la proposition technique et la proposition financière quand on le demande. Les prix viennent des dossiers de demo/ et ne sont pas présentés comme une grille.

Cas d’usage

  • Un prospect décrit une plateforme de visio et de traduction : la formule Mobilité (19 500 € HT) est retenue si l’ampleur est standard.
  • Un prospect décrit une application mobile : le socle Flutter / Strapi (21 495 € HT) est retenu.
  • Un site vitrine n’a pas de forfait de référence : les lignes sont au taux de 450 € HT et le document le signale.

Sécurité

  • Les clés API ne sont lues que sur le serveur. Aucun préfixe NEXT_PUBLIC_.
  • Le texte du prospect est validé (40 à 8 000 caractères) et n’est pas écrit dans les journaux.
  • Le modèle reçoit la formule déjà chiffrée. La réponse JSON est rejetée si elle ne respecte pas le schéma. Les montants affichés viennent du serveur.
  • Limite de 8 dossiers par minute et par adresse.
